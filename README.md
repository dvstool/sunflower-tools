## 📥 Installation Guide (Pro Edition)

To access Silver and Gold features, download the compiled and protected package from the **Releases** section:

1. Go to the **[Releases](../../releases)** tab of this repository.
2. Download the latest `Sunflower-Tools-vX.X.X-pro.zip` file.
3. Extract the downloaded `.zip` file into a folder on your computer.
4. Open your Chromium-based browser (Google Chrome, Brave, Microsoft Edge, Opera):
   - Navigate to: `chrome://extensions`
5. Enable **Developer mode** toggle in the top-right corner.
6. Click **Load unpacked** in the top-left corner and select the extracted folder.
7. Open [Sunflower Land](https://sunflower-land.com/play/), connect your Web3 wallet, and click the Sunflower Tools sidepanel icon to start!
